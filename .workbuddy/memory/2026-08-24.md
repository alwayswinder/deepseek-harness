## 关键坑：WorkBuddy 安全删除 shim 会拦截 pnpm/node 的删除操作

- WorkBuddy 通过 `NODE_OPTIONS=--require=.../genie-safe-delete.cjs` 给所有 node 进程注入 fs 删除劫持（删除走回收站 trash）。
- pnpm install 在 createStoreController 阶段删 store 临时目录 `_tmp_*` 时被 shim 拦截，trash 失败报 `[safe-delete] 操作失败 ... Some operations were aborted` 退出。
- **解法**：运行 pnpm/node 命令前 `unset NODE_OPTIONS CODEBUDDY_SESSION_ID CLAUDE_SESSION_ID`（shim 检测不到会话 ID 会零开销退出）。注意每次 Bash 调用都会重新注入环境变量（BASH_ENV 加载），需在同一命令行内 unset。
- `pnpm run build`（约 4.5 分钟）和 `pnpm dsh web` 启动同理都要 unset。dsh web 启动后需等 ~1 分钟初始化，期间根路径返回 404，初始化完成后 200。
