# 3ds Max 角色适配流程（Biped 重建 → 控制器迁移）

[English](README.md) | 中文

本目录指导你为角色配一具拟合到自身骨架的 Biped，并按参考 rig 的语义迁移身体控制层；角色自己的骨架保留为导出对象。流程是通用的：所有数量、长度、控制名与试动量都来自本轮的 profile。Stan 与 Chiya 是案例，它们的尺寸、节点数与测试位移是证据，不是默认值。

## 从哪里开始

先填[新角色适配记录](character-adaptation-guide.md)，再按[操作清单](quick-runbook.md)推进。每轮由三份 profile 驱动：body profile（骨名、父级、角色标签、静止矩阵）、Biped profile（参考 rig 的结构参数）、rig profile（链、环、极向点、辅助点、控制器树、wire）。

| 输入情况 | 起点与限制 |
|---|---|
| 静态人形、无骨架 | 按身体骨架指南建立 profile 定义的节点；Chiya 参数只是一个实测案例 |
| 同拓扑、骨轴相容 | 按操作清单拟合并逐阶段验证控制器迁移 |
| 同拓扑、完整骨轴不相容 | 做整链拟合与固定旋转偏移参考层验证；最终控制器输出适配未完成，不能继续普通双树复制 |
| 骨数、层级、脊柱、手指或 twist 配置不同 | 先按适配指南 §4 做映射与 profile 适配；现有脚本不能直接套用 |
| 无 Skin | 在分支限制内测试骨架与控制行为；蒙皮与变形标为不适用 |

## 执行顺序与通过范围

每阶段另存 `<角色>_<阶段>_<日期>.max`，外部保存身体骨名与父级、静止矩阵、映射表、rig 语义表与测试记录。会话全局不承担持久化；文件名也不代表验收通过。

| 阶段 | 输出或检查 |
|---|---|
| 0 输入 | 原始输入与工作副本、单位、绑定状态、身体骨清单、落盘静止表、填完的适配记录 |
| 1–2 Biped | 源结构与本轮 figure、目标髋宽、逐侧长度及骨轴分类；转换分支在映射验证后停止 |
| 3 测量层 | 相容分支的 BIPDRV，Root/twist 分别处理，原身体骨静止不变 |
| 4–5 控制层 | 按碰撞清单合并隔离名字、复制位置与旋转双树、重指约束及全部绑定 |
| 6–7 几何 | 先摆环再拟合静止链、对齐手柄、复核段长，最后求脊柱 percent |
| 8–9 行为 | Biped 驱动的姿势差分、环驱动响应、根平移与转向、四肢越界、按节点类别判直接复位 |
| 10 保存 | 按源清单设置显示；保存重开，按引用快照逐节点比较 |
| 导出 | bake → FBX → UE 尚未验证，暂无完成验证的操作规范 |

严格整体验收仍未闭环。2026-10-19 第三轮通过了静止链路（拟合、驱动层、合并、重指、静止对齐），但动态项未通过：姿势差分（腿 0.406、臂 6.23，源为 0.0106/0.0013）、根转向（`calf` 翻转 179.9°，源 0.007°）、左臂越界末端距环 1.168（源 0.0020）、直接复位 6.5e-3、重开在求解器驱动节点上漂移 2.05e-4。分项结果与失败数值见[适配指南的证据表](character-adaptation-guide.md#6-已有证据与边界)。静止合格或重载恢复都不能替代整体验收。

## 窗口与显示态（每轮开工前先切好）

A、B 各用一个 Max 实例，按完整文件路径与 PID 确认身份。A 只读取证，B 在另存的工作副本中施工。显示态存入场景，重开后回到保存时的状态。

| 用途 | 操作 |
|---|---|
| 取源结构 | 按本轮源图层清单放通控制器层及其全部父层，同时隐藏无关旁支 |
| 目标施工 | 按本轮目标图层清单显示网格、控制环与目标 Biped；隐藏源遗留与测量点 |
| 视口对照 | 两个窗口统一 Front / Standard / Edged Faces，再检查三视图中的关节与骨轴 |

`PrinceofStan`、`不导出/控制器` 之类是历史案例名，不是新角色必须具备的名字。图层自身勾选位不能证明有效可见：父层会隐藏子层，放通父层还可能放出面部等旁支。按实际节点可见状态复核，并逐节点移层。

## 测量与恢复纪律

写入后调用 `completeRedraw()`；判定前退出 Figure Mode，强制求值并在同一次调用内连读两次。以本轮外部静止表作为拟合真值，不读取已受约束影响的骨当前值。逐骨比较静止与姿势误差，避免静态补偿掩盖运动错误。

三种判定必须分开。姿势差分由 **Biped 骨**驱动（移动 Biped 骨，比较身体骨与 BIPDRV）。环响应由**控制环**驱动（移动环，检查身体骨等量同向、Biped 是否如源实测那样不动）。每条行为门槛同时记录**源 rig 在同一姿势下的实测值**，因为绝对门槛可能严于源自身的能力。

每组试动后直接复位，并用**引用快照**比较全部受影响节点，不能用名字：场景里可能存在同名对象。失败组记录节点与残差后重载里程碑隔离下一组；重载不算直接复位通过。重开后丢弃旧包装器、按名字重新解析，并按迁移指南做正向依赖与显式绑定检查。

节点矩阵一律与引用快照比较，并把**求解器驱动节点**（IK 链关节等）单独报告：它们无法在重开或复位后逐位复现，判据是"不劣于源基线"。
