# 新角色适配：输入检查、参数记录与分支选择

本页定义换角色时必须重新测量的内容。先建立本轮角色记录，再按[操作清单](quick-runbook.md)施工；Biped 算法见[重建指南](biped-rebuild-guide.md)，控制器算法见[迁移指南](controller-migration-guide.md)。Stan 和 Chiya 的数值仅是案例证据。

## 1. 先判断能走到哪一步

当前流程以 **Seven 兼容的 55 身体骨拓扑**为起点：52 根普通对应骨、2 根前臂 twist、1 根 Root。该配置的参考 Biped 为 71 对象（58 Biped_Object、13 Dummy Nub），结构参数见重建指南步骤 2。这些是指定配置的数量，不是所有角色的标准。

| 输入 | 可执行范围 | 继续条件 |
|---|---|---|
| 无骨架的静态人形 | 按[身体骨架搭建指南](static-body-skeleton-guide.zh.md)准备实测 55 骨，再做以下检查 | 每个角色独立测量；Chiya 参数不能直接套用 |
| 55 骨拓扑、骨轴与参考控制器相容 | Biped 拟合、测量驱动层、路线 1 控制器迁移及完整验收 | 每阶段实测通过；已有 Stan 实验也未全部通过整体验收 |
| 55 骨拓扑、相邻关节完整骨轴不相容 | 整链几何拟合、冻结旋转偏移、映射参考层验证 | 当前止于映射验证；最终控制器旋转输出尚需接入偏移并验证 |
| 数量、父子层级、手指/脊柱/twist 配置不同 | 盘点与差异记录 | 先提供新的骨名映射、Biped 配置和控制器适配；现有脚本不能直接套用 |
| 无 Skin | 骨架、关节拟合、满足分支条件后的控制器行为测试 | 蒙皮名单/变形验收标为“不适用：无 Skin”，不得计为通过 |

同名、同层级、每段 +X 沿骨长只说明部分条件一致。还必须检查完整静止旋转、双侧髋关节布置、整链弯曲平面和源控制器语义。外观接近也不能替代这些检查。

## 2. 每个角色独立记录什么

将以下模板复制为本轮外部记录，例如 `work/<角色>_<日期>/adaptation.md`，所有空项在进入相关阶段前补齐。外部记录和静止表随里程碑一起保留；会话全局变量不承担持久化。`work/` 不纳入 Git，交接时必须同时提供记录和场景文件。

```markdown
# <参考角色> → <目标角色> 适配记录

- 源输入路径 / Max 实例 PID / Max 版本：
- 目标原始路径 / 工作副本路径 / Max 实例 PID：
- 目标状态：静态无骨 / 自由骨架 / 已有控制器（先隔离）
- 系统单位 / 显示单位 / 世界上轴 / 前方向 / 静止帧：
- 目标网格及 Skin 状态 / 每网格骨名集合 / Skin 并集：
- 身体骨配置 / 精确骨名表 / 父节点表 / 源→目标名称映射文件：
- 原始世界静止矩阵文件 / 单位缩放与控制器检查结果：
- 源 Biped 根名 / 全部结构属性 / 节点清单 / 本轮导出 figure：
- 每侧臂腿上下段长度 / 肩髋中心 / 髋宽 / 骨盆局部宽度轴：
- 每侧肩肘腕、髋膝踝坐标 / 近共线链的弯曲平面参考：
- 轴系分类：直接相容 / 需要转换 / 未确定（附逐骨误差）
- Biped 拟合目标文件 / 每骨冻结旋转偏移文件（需要转换时）：
- 控制层语义表文件 / IK 求解器、长度轴、位置槽和伸缩绑定：
- 临时命名集 / 合并节点清单 / 保留节点清单 / 源遗留节点清单：
- 验收参数：单位换算、四肢试动向量、根平移/转角、环位移、越界距离：
- 每阶段里程碑 / 逐骨静止及姿势误差 / 直接复位 / 保存重开差：
- 本轮结论：通过范围 / 失败节点与数值 / 未测试项 / 下一步：
```

**从明确的身体骨名表取静止矩阵**，每骨记录名字、父节点和世界 matrix3 的 12 个数字。不要按场景全部 Dummy 抽取：其他辅助点与 Biped Nub 也可能是 Dummy。新建 55 骨可从 body55 参数文件取得名称和层级；已有骨架必须逐项核对，不能仅比较总数。

Skin 名单按网格分别读取并取并集，确认其节点属于记录中的绑定集合。Stan 的并集 54、Root 不蒙皮是该角色的绑定事实；新角色的合法并集由自身绑定设计确定。额外毛发、衣物和面部骨需列出归属与处理范围，不能混进 55 身体骨，也不能无声遗漏。

控制层语义表至少包含每侧起环、肘/膝环、腕/踝环、脚掌环、链起中末关节、极向点、Expose、控制根、脊柱 Path 点、共享手指环及其依赖。记录源节点名、目标职责、父局部矩阵、控制器树、约束目标和 wire/script 绑定。最近距离只帮助找候选，最终对应关系要以层级、引用和源窗口试动确认；不能仅凭 `Circle015` 这样的编号推断职责。

## 3. 区分配置常量与角色实测值

| 类别 | 使用规则 |
|---|---|
| 配置数量 | 当前配置为 55、52+2+1，参考 Biped 71；更换配置必须更新对应表与实现 |
| 每角色几何 | 段长、肩宽、髋宽、轴向、手指位置、骨盆中心全部来自本轮原始静止表 |
| 每参考 rig 行为 | 环/链节点名、求解器、长度轴、控制器槽、权重、合法附件偏移、伸缩函数都从源实测 |
| 每轮派生数量 | 临时改名、源遗留、保留对象、约束目标、Expose、显示盒数量按清单计算；126、324、1003、56/71 不是通用门槛 |
| 需重新求解的参数 | 脊柱 percent、极向点平面、手柄偏移、伸缩阈值不复制 Stan 的结果 |

对于 Seven 的等分越界伸缩函数，目标阈值由目标两段静止长度计算 `H=(L1+L2)/2`。其他源 rig 先确认实际函数及方向，不能假设都使用这个公式。更新后仍须比较实际段长、末端跟环及复位，表达式文本正确不足以证明行为正确。

## 4. 两项最容易遗漏的适配

先检查**髋宽**。装载源 figure 只是获得初始形体。在 Figure Mode 中，实测并确认骨盆的局部宽度轴，按目标/当前髋间距缩放，再重做骨盆中心定位并逐侧量大腿起点。若目标双髋有高度、深度或不对称差异，单个宽度比例不保证可解，不能把平均髋宽达标当作两侧都通过。具体操作见重建指南步骤 4。

再检查**整链骨轴**。若对齐前臂又使上臂偏转、对齐小腿又使大腿偏转，停止重复逐骨旋转迭代。用肩肘腕、髋膝踝构造共同弯曲平面的 Biped 目标轴，近共线时提供稳定平面参考。原导出骨及原始静止矩阵保持不变，另存 Biped 目标和去除缩放、平移后的世界旋转行矩阵偏移：

```text
O = R_target_rest * inverse(R_Biped_rest)
R_expected_pose = O * R_Biped_pose
```

该顺序适用于本流程采用的世界行向量约定。不能将矩阵乘法顺序、普通节点四元数赋值与 Biped API 的约定混用。创建参考点后逐点读回，再用冻结的 O 验证静止、四肢弯曲、根平移与转向；每个姿态重新算 O 会掩盖跟随错误。

同轴分支比较原骨与对应 Biped/驱动点朝向；转换分支比较原骨轴下的预期朝向。两者分别记录。`BIPMAP_*` 是转换分支的测量参考层，不驱动原骨，不等于 `BIPDRV_*`；52 普通点的验证不覆盖 Root 和两根 twist。**控制器最终输出未接入同一偏移并验证前，转换分支停止，不进入普通双树复制流程。**

## 5. 验收尺度与复测方式

位置阈值以 **cm** 表达，使用场景数值前按系统单位换算；显示单位不能代替系统单位检查。当前标准不随角色放大而放宽：Biped 拟合 ≤0.05 cm / ≤0.1°，迁移后 ≤0.1 cm / ≤1°，链起末端 <0.002 cm、中关节 <0.02 cm，直接复位 ≤0.0001 cm。段长记录原始精度并报告逐段残差，不用格式化后的字符串判断相等。

试动距离按本轮体型和关节可达范围确定并在运行前固定，确保产生可测的肘膝弯曲。既有 Stan/Chiya 试验的手脚 +25Z、根 +10Z，以及 Stan 的环 +5、越界多出 20 cm，都是案例测试量；Chiya 映射参考层另测了根转向 15°，没有测试完整控制环迁移。这些数值不适用于任意尺寸。每侧四肢分别测，另测根平移与转向；记录请求位移和实际位移，不能让未真正动起来的测试通过。

越界测试按各自两段总长加记录的超出量，将源与目标置于可比的相对伸展程度；不同体型不能简单使用相同末端世界坐标。环的 1:1 响应和 Biped 是否反驱仍按源行为同测。无 Skin 时也要检查骨架数值，但不能据此推断变形质量。

每组试动前保存所有受影响节点变换，试动后直接恢复并测全体节点；失败后重载仅用于隔离下一组，不算复位通过。逐骨比较姿势前后误差，不能只比较全局最大值。保存重开同时报告逐节点位置、角度、矩阵分量差；当前严格一致性要求差为 0，不能用“仍低于静止门槛”替代，不能为某角色临时放宽标准。

写入后 `completeRedraw()`；判定前退出 Figure Mode，强制求值，在同一次调用内连续读两遍。角差以规范化旋转计算；接近零时优先使用四元数向量部分和标量部分的 `atan2` 形式，避免只用 `acos(w)` 舍入为零；MAXScript 三角函数使用度。锁骨还需几何方向复核，不能要求其两个自由度实现任意完整旋转。
