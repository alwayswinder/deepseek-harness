# 身体控制器迁移指南（源 rig 控制环 → 目标角色）

> **一句话**：把源角色 A 的控制环（起/末端环、膝/肘环、辅助 IK 链、极向点、参数线）搬到目标角色 B 身上，"静止对准"只是**必要不充分**条件；必须用**驱动源分离的差分指标**验收，否则会得到"静止全对、一动就炸"。
>
> 适用：A 带 Biped、原生控制环、辅助 IK 链与极向点；B 使用同构身体骨并保留自己的导出骨架。B 可以没有 Skin，此时只验骨架与控制行为，变形与引擎导出标为不适用。
> 本文不绑定固定角色：环/链/极向点的编号、数量、段长、试动量全部来自本轮的 **rig profile** 与适配记录。Seven → Stan 的数值一律标注为样例。

---

## 0. 架构、前提与驱动源

```
摆姿势入口（两条都成立，但不能互相替代验收）
  ├─ 动 Biped 骨 ──> 环跟随 ──┐
  └─ 动控制环 ───────────────┤
                              ▼
                    源 rig 控制环（环 → 辅助 IK 链 → 膝/肘环）
                              ▼
                    目标 UE 骨（Dummy/蒙皮对象）
                     位置 ← 环；旋转 ← 逐骨复制源结构
                              ▼
                          Skin → 角色网格
```

| 前提 | 判据 |
|---|---|
| 骨轴与源控制器相容 | 适配记录已判定"直接迁移"；整链变换分支不进入本文 |
| B 的 Biped 已拟合达标 | 见[重建指南](biped-rebuild-guide.md)§3 |
| B 的骨架自由 | 普通骨仍为自由控制器；导出根已按重建指南单独约束 |
| 测量基准已建 | `BIPDRV_*` × `N_body` 跟随对应 Biped 骨 |
| 源 rig 可读 | A、B 开在两个 Max 实例，A 只读取证 |
| rig profile 已产出 | 链/环/极向点/辅助点/Expose/控制器树/wire 的语义表 |

### 0.1 四条放大机制（静态门槛全看不见）

**1.1 近全伸展的径向放大**：中关节离轴高度 `h ≈ sqrt(L·δ)`（`L` 上段长，`δ = L1+L2−d` 冗余量），`dh/dδ ≈ 0.5·sqrt(L/δ)`。段长分配错一点，膝/肘就偏一大截。
> 例：源段长 36.61/43.96、目标 35.30/45.39，总长只差 0.12，中关节离轴高度从 2.26 变 0.67 → 静止膝偏 2.5。

**1.2 静态补偿活在旋转坐标系里**：为让静止"好看"而写进膝/肘环的固定偏移，会跟着关节一起转，而它要抵消的误差随弯曲改变大小与方向 ⇒ 静止准、一动原样回来。

**1.3 等权多目标是取平均**：把 UE 骨旋转写成两个 `Orientation_Constraint` 各权重 100，结果是两个朝向的球面平均；两个目标一分开，误差就是夹角的一半。
> 例：抬脚 +10 时两目标夹角 59.17°/29.70° → 混合后相对 Biped 差 29.59°/14.85°。

**1.4 `LookAt` 的滚转来自 `pickUpNode`**：上方向节点若仍指向源骨架的骨，静止时恰好"看着对"，一弯就错。

### 0.2 三条判据必须分开（本轮新增）

| 判据 | 驱动源 | 目的 | 不能混用的原因 |
|---|---|---|---|
| **差分** | Biped 骨 | UE 骨 vs `BIPDRV` 的误差是否随姿势增长 | 动环**不会**反驱 Biped（源 rig 实测 0.000），用动环做差分会把"设计如此"误判成迁移失败（本轮实测误判值 29.33/49.1°） |
| **行为** | 控制环 | 环到 UE 骨是否 1:1、Biped 是否如源一样不动 | 与差分相反，不能用 Biped 驱动 |
| **基线** | 源 rig | 同一姿势下源自身的漂移 | 绝对门槛可能严于源自身能力（见 §3） |

## 1. 步骤 1 — 盘点与语义表（只读）

在两个实例各跑一次只读盘点：

| 项目 | 取法 |
|---|---|
| 类直方图 | 有 `IK_Chain_Object` 像源 A，没有像目标 B |
| 每条 IK 链 | `<链节点>.transform.controller.startJoint / endJoint`；中间关节 = `endJoint.parent`；另读 `IKSolver`、`VHTarget`、`useVHTarget`、`posThresh`、`iterations` |
| 链的 goal | 链节点通常**挂在腕/踝环之下**（本轮实测），goal 即该环 |
| 膝/肘环 | 是否为链中关节的子级（本轮实测：是） |
| 极向点候选 | 被 `IKChainView`/`VHTarget` 引用的 Point，且不在链关节上 |
| 环 ↔ 关节 | 用约束反查：每个 UE 骨的位置约束目标就是它的环；**不要按 `CircleNNN` 编号猜职责** |
| 辅助点层次 | 环的父级是普通 Point 还是链关节；父级自身有没有约束 |
| Expose 助手 | `<o>.exposeNode` / `localReferenceNode`；并实测它是**静态**还是跟随暴露节点 |
| 控制器树 | 每个 UE 骨的 `position_list` / `rotation_list` 槽位、控制器类、权重、目标 |
| wire / 表达式 | 各位置槽上的 expression/float_limit 与其绑定节点 |
| 蒙皮与层级 | 网格的 Skin 名单、图层清单 |

**语义必须用受控试动确认**（最近距离只能找候选）：

| 试动 | 观察 | 结论 |
|---|---|---|
| 移动一个候选环 +5 | 哪根 UE 骨等量跟随、Biped 是否动 | 环的职责与"是否反驱 Biped" |
| 移动一根 Biped 骨 | 哪些环/UE 骨跟随 | 跟随方向 |
| 移动链关节 | 谁跟随/谁不动 | 链与环的层级 |

产出：**rig 语义表**（链、环、极向点、辅助点、Expose、控制器树、wire、依赖方向），作为后续唯一依据。最近距离、节点编号、图层名都不构成依据。

## 2. 步骤 2 — 合并与名字隔离

1. 建碰撞清单：至少 `N_body` 身体骨 + `N_biped` Biped 骨 + 目标已有的同名辅助点；外部保存节点身份与原名。
2. 目标侧加 `TGT_` → 合并源文件 → 给合并来的碰撞节点加 `SV_` → 还原目标名。
3. 校验：目标/源 Biped 各 `N_biped`；临时前缀残留 0；两侧唯一可解析；重名清单只允许来自源文件本身（本轮源文件自带 1 例同名）。

> 坑：合并会**合并同名图层**、**带入源的隐藏状态**；之后"取消隐藏父层"会级联放出源的面部层。

## 3. 步骤 3 — 复制位置 + 旋转两棵控制器树

```maxscript
for bn in bodyNames do (          -- bodyNames 是已核对的 N_body 清单
  if (bn != rootBoneName) do (    -- 导出根例外：它由 BIPDRV 驱动
    local src = getNodeByName ("SV_" + bn)
    local dst = getNodeByName bn
    if (src == undefined or dst == undefined) do throw ("缺映射节点: " + bn)
    dst.pos.controller      = copy src.pos.controller   -- 位置侧必须一起复制
    dst.rotation.controller = copy src.rotation.controller
  )
)
```

- 复制集 = `N_copy = N_body − 1`（含 twist 骨）；常规验收集是 `N_map`。
- **位置侧必须复制**：只复制旋转会得到"动 Biped 会跟、动控制器不跟"的半成品。
- 典型源结构（本轮实测，**其他源必须自己读**）：`rotation_list` = `[1] Euler_XYZ` 基值 + `[2] LookAt/Orientation` 权重 50；`position_list` = `[1] 冻结值` + `[2] Position_Constraint → 环`。
- 复制后骨会大面积偏向"源几何"（本轮 52/52 偏 >0.2，最大 6.96），这是允许的中间态，交给步骤 7。

## 4. 步骤 4 — 引用重指（必须在解链之前）

要重指的四类位置：

| 位置 | 源指向 | 改成 |
|---|---|---|
| 约束目标 | 源骨架的骨（`SV_bip001 …`） | 目标同名骨 |
| `LookAt.pickUpNode` | 源骨架的骨 | 目标同名骨 |
| `LookAt` 的目标 | 源的中点环 | **先量再决定**：中点环落在线段上就保持源目标；明显离线才改指关节环 |
| `ExposeTm` 字段 | 源骨架节点 | 目标对应节点 |
| 控制层根 | 源静态根 | 本轮目标导出根 |

**重指方法（Max 2026 实测）**：`Orientation_Constraint` / `LookAt_Constraint` **没有 `SetNode`**，只能：

```maxscript
-- 保持节点当前变换不变：appendTarget 会捕获当前偏移
c.appendTarget newTarget 100.0
c.deleteTarget oldIndex            -- 多目标时按索引倒序删
-- 改完读回目标名，并比较节点世界变换没有跳变
```

**`ExposeTm` 先判定再改**：

| 判定 | 方法 | 处理 |
|---|---|---|
| 静态助手（本轮实测 6 个全部如此） | 在两个不同姿势下比较助手与 expose 节点的世界变换；不跟随即静态 | 只改 `exposeNode`/`localReferenceNode`，**不要**把助手吸附到骨上（会挪走其下游的极向点） |
| 跟随助手 | 世界变换等于 expose 节点 | 改字段后再核对位置 |

**正反向检查**：

- 正向：从全部保留节点递归 `refs.dependsOn`，先 `isValidNode` 再读 `.name`；命中源骨架即为残留。
- 反向：`refs.dependents <SV_节点>` 出现保留节点是正常的（源骨依赖共享控制点），不能据此断言保留节点引用源骨。
- 另需显式核对控制器 targets、`pickUpNode`、`ExposeTm` 字段与 wire/表达式绑定——浅层扫描不能证明间接引用已清。

**门槛**：保留节点到源骨架的引用 = 0；重指后节点世界变换不跳变。

## 5. 步骤 5 — 摆环（解链前）

1. 起环、腕/踝环以对应 `BIPDRV` 点落位；脚掌环同理。
2. **落位要改环的普通父辅助点，不要直接 `move` 环**：环到父级的局部关系是源 rig 的语义，直接移环会让它在父级旋转时绕错基准。
3. 膝/肘环挂在链中关节下，随链重解移动，**不要**用它们的局部偏移去凑位置。
4. 记录每个环的父级类型（普通点 / 链关节 / 有约束的点），后续步骤据此决定能不能移动。

**门槛**：起环/末端环/脚掌环相对 `BIPDRV` 残差 ≤1e-4（本轮 ≤8.1e-6）。

## 6. 步骤 6 — 链的静止几何

链关节是 Point，`pos.controller` 是 `position_list`：`[1]` 冻结值、`[2]` 偏移/动态伸缩。**有效局部向量 = `p1 + p2`**（实测恒等式误差 ~1e-6）。

### 6.1 先测，不要假设

对每段读 `p1`、`p2`、`p1+p2` 的长度与方向，记录：

- 长度分量在哪个分量上（本轮腿/臂都在 `p1.x`；**不要**照抄"臂在 p2.y"这类个案结论）；
- 求解器类型（本轮右腿 `IKHISolver`，其余 `IKLimb`）；
- 第二槽的动态伸缩来源（expression / wire / limit）。

### 6.2 再写

```maxscript
-- 仅当有效向量沿局部 +X 时：
local p1c = (getSubAnim j.pos.controller 1).controller
local p2c = (getSubAnim j.pos.controller 2).controller
p1c.value = ([L, 0, 0] - p2c.value)      -- L = 本轮静止表里的该段骨长
completeRedraw()
```

若有效向量不沿 +X，按实测方向构造：`p1 = normalize(dir) * L - p2`。

### 6.3 校验与残差政策

| 指标 | 门槛 |
|---|---|
| 链起点/末端相对 `BIPDRV` | <2e-3 |
| 链中关节 | <0.02 |
| 两段实测长度 | 与静止表一致（记录原始精度） |

**求解器残差**：收紧 `posThresh`（0.1→0.0001）、加 `iterations`（40→200）、退避后重解都没改善的末端偏差，按"该链求解器残差"记录（本轮左腿 3.7e-3、右腿 2.4e-5）。
**禁止**：写链关节 `.rotation` 或 `move`（会触发 IK 重解并改坏段长）；用环偏移吸收残差。

## 7. 步骤 7 — 静止偏移对齐

复制结构后骨会偏向源几何（本轮 52/52 >0.2）。对"普通父辅助点下的环"，用关联骨的平均误差迭代回写（阻尼 0.6）：

```maxscript
-- 每轮：delta = mean( BIPDRV_位置 − 骨当前位置 )，然后 in coordsys world ( move 父辅助点 (0.6*delta) )
-- 目标用 BIPDRV，不要用已被控制器影响的 UE 骨当前值
```

| 规则 | 说明 |
|---|---|
| 跳过 | 起环、末端环（已落位）、脊柱 Path 点（步骤 9 扫 percent）、挂在链中关节下的膝/肘环 |
| 肩环/脚掌环 | 优先保留源环到父辅助点的局部关系，**改父辅助点**的落位 |
| 手指环 | 共享手柄上会振荡：改逐骨验证式贪心（每步只接受让该骨误差下降的移动），或跳过已对齐的手指环 |
| 收敛判据 | 每轮复测，误差不再下降即停；不要无限加轮数 |

**门槛**：`N_map` 根骨相对 `BIPDRV` ≤0.1 / ≤1°（本轮 0.0178 / 0.0914°）。

## 8. 步骤 8 — 极向点校准

**前提**：链的起/末端已落位、段长已设好、偏移已对齐。

### 8.1 先判断静止平面是否退化

```
h = |perp( BIPDRV_mid − S , k )|,  k = normalize(H − S)
```

- `h < 0.02 × 段长` ⇒ 静止平面退化，只能在弯姿势校准（把该判断写进记录）。
- 否则静止平面有效，按"起环、末端环、目标中关节"三点定平面，把极向点绕轴旋到该平面（保离轴距离）。

> 本轮实测 `h ≈ 2.2`（约段长 6%），静止平面**有效**：按静止校准后中关节 0.257 → 0.00011。旧文"静止时平面退化、怎么转都没效果"在本 rig 不成立——先量 `h` 再下结论。

### 8.2 弯曲核对

按适配记录的弯姿势测中关节误差，并计算平面夹角：

```
θ = angle( perp(chainMid − S, k) , perp(bipedMid − S, k) )     预期误差 ≈ h · sinθ
```

若实测与 `h·sinθ` 同量级，说明误差来自**平面不匹配**，不是段长或求解器问题。

### 8.3 冲突处理（必须记录，不能掩盖）

单一静态极向点只能满足一个姿势的平面：

| 本轮实测 | 值 |
|---|---|
| 腿弯 +31% 肢长 | 中关节 **0.406**；另一次同姿势诊断（求值状态不同）测得 `θ = 2.51°`、折叠后 `h = 35.19`，`h·sinθ = 1.54` 与实测 **1.543** 吻合——估算式成立，误差来源确认为平面不匹配 |
| 臂弯 59° | 中关节 **6.23**、朝向 **18.1°** |
| 双平面折中解（同时落在静止与弯曲平面） | 静止仍达标，弯曲 **6.23 → 7.40（更差）** |

可选路径：

1. 接受并在记录里写明 `θ`、`h`、误差，把该姿势判为失败；
2. 让极向点随肢体转动（挂到随骨骼旋转的父级，使平面跟随）——**本轮未验证**，必须单独验收后才能作为通过方案；
3. 双平面折中解**不可用**（实测更差）。

**禁止**：用膝/肘环的局部偏移吸收平面误差；把"环落在关节上"当作极向点正确。

## 9. 步骤 9 — 伸缩、wire 与脊柱参数

1. 从源实例读每条 wire/expression 的绑定、表达式、限制器与实际输出。
2. 阈值按本轮**落盘静止两段总长**重算（等分越界函数：`H = (L1+L2)/2`；其他函数按源语义推导）。
3. 验证动态输出：弯曲与越界时测实际输出与上下段实测长度；`p1+p2` 若不沿局部轴，沿该轴增长不等于实测段长增加。
4. **不要把动态输出吸收进第一槽**：`+0.0385513` 之类只是某姿势下的读值，不是常量。
5. 脊柱 `Path_Constraint.percent` **最后**分批扫描（本轮最优点恰为现值 50.0 / 100.0，误差 0.0017 / 3.8e-5）。

## 10. 步骤 10 — 差分、行为与越界验收

### 10.1 差分（Biped 驱动）

按适配记录分别移动双脚、双手对应的 **Biped 末端骨**（本轮 +31% 肢长），测 `N_map` 根骨相对 `BIPDRV`：

| 指标 | 门槛 | 本轮实测 |
|---|---|---|
| 位置 | ≤0.1 | 腿 0.406（失败）、臂 6.23（失败） |
| 朝向 | ≤1° | 腿 0.81°、臂 18.1°（失败） |
| 误差增长 | 逐骨比较，不能只看全局最大值 | 逐骨已比较 |

**必须与源同姿势对照**（见 §3）。

### 10.2 行为（控制环驱动）

| 测试 | 判据 | 本轮实测 |
|---|---|---|
| 腕/踝/肩环 +位移 | UE 骨等量同向；Biped 是否跟随按源实测（Seven 源为 0） | 三个环均 **+5.000** 精确，Biped 0.0 ✓ |
| 根平移 | pelvis/head/双手/双脚保持预期跟随 | 六个探针全部 +10.000 ✓ |
| 根转向 | 同上，且不出现关节翻转 | `calf_l` 翻转 **179.9°**（失败；源 0.007°） |

### 10.3 越界

把末端环拉到"两段总长 + 记录超出量"，记录两段增量、末端到环距离，与源在可比伸展度下同测。

| 本轮 | 目标 | 源 |
|---|---|---|
| 腿两段增量 | +10.000 / +10.000 | +10.000 / +10.000 |
| 腿末端距环 | 0.0154 | 0.0035 |
| 臂两段增量 | +9.40 / +9.40 | +9.96 / +9.96 |
| 臂末端距环 | **1.168** | 0.0020 |

### 10.4 直接复位（按节点类别判）

每组试动前快照全部受影响节点（**用引用**，同名节点不能按名字），试动后直接移回，`completeRedraw()` 后逐节点比较。

| 节点类别 | 门槛 | 本轮 |
|---|---|---|
| 非求解器节点（Biped 骨、环、UE 骨、辅助点） | 位置残差 ≤1e-4 | 左脚组 **5 个节点 6.5e-3（失败）**；右脚 8.6e-5 ✓；左手 9.1e-5 ✓；右手 1.5e-4（1 节点） |
| 求解器驱动节点（IK 链关节及其下游） | **不劣于源基线** | 源自身复位残差 0.0021；本轮 0.0065（比源差 3 倍） |

> "重载里程碑恢复"不算直接复位通过；失败组合记录后重载隔离下一组。

## 12. 验收速查

| 项目 | 门槛 | 说明 |
|---|---|---|
| 链起点/末端（静止） | <2e-3 | 求解器残差逐链记录 |
| 链中关节（静止） | <0.02 | 极向点校准后 |
| 链中关节（弯姿势） | 与静止同量级 | 冲突时按 §8.3 记录并判失败 |
| 差分位置/朝向 | ≤0.1 / ≤1° | Biped 驱动；并对照源 |
| 环 1:1 | 等量同向 | 环驱动；Biped 响应按源 |
| 根平移/转向 | 预期跟随、无翻转 | 对照源 |
| 越界 | 两段等分、末端跟环 | 与源同伸展度对比 |
| 直接复位 | 非求解器 ≤1e-4；求解器不劣于源 | 引用快照 + 逐节点 |
| 保存重开 | 同上分类 | 结果写进记录 |
| 显示 | 与源清单一致 | `boxMode` 数量按清单 |

**判定原则**：绝对门槛与源基线**同时**使用。绝对门槛达到即通过；达不到时，只有"不劣于源 + 差值可解释"才能记为"与源等价"，且必须在适配记录中写明，不能用"固有残差"一笔带过。

## 13. 陷阱速查

| 症状 | 原因 | 修法 |
|---|---|---|
| 静止对、一动就炸 | 链段长仍是源角色的 + 静态补偿 | 步骤 6 + 8 |
| 静止差 2–7°，一动差 15–30° | 旋转被写成多目标等权混合 | 步骤 3 `copy` 源结构，不要自叠目标 |
| 手臂一弯差 16–23° | `LookAt.pickUpNode` 指向源骨架 | 步骤 4 改指目标同名骨 |
| 越"修"差得越多（2.5 倍响应） | `appendTarget`/`Constraint()` 在列表里是**追加** | 先 `deleteTarget`（倒序）或整棵 `copy` |
| 骨长怎么调都不守恒 | 长度分量不在 p1.x；第二槽还含动态伸缩 | 步骤 6 先测再写，只写冻结槽 |
| 极向点转了没反应 | 静止平面真的退化（`h` 很小） | 先量 `h`；退化时在弯姿势校准 |
| 极向点静止与弯曲互相打架 | 单一静态极向点只能满足一个平面 | §8.3 记录冲突或改设计；双平面折中不可用 |
| 动一根骨，另一根不应动却动了 | 用绝对坐标设链关节位置（= 改骨长） | 链关节只写冻结槽；`move` 只用于非链普通辅助点 |
| 动角色根后膝平面全错 | 控制层根挂在源静态根上 | 步骤 4 改指目标导出根 |
| 约束都改指了，删源层后还有零件跟源走 | wire/表达式也引用源对象 | 步骤 4 正向依赖 + 显式绑定 |
| 脊柱某节静止偏 1–2 单位 | 样条 `percent` 是源角色的比例 | 步骤 9 扫描 |
| 普通环写 `obj.pos` 不生效 | 控制器含冻结位置/零位置槽 | 环用世界坐标 `move` 并回读 |
| 遍历控制器只找到一小部分引用 | `ctrl[j]` 得到的是 SubAnim 包装 | 用 `ctrl.numSubs` + `getSubAnim c j` + `.controller` |
| 读到旧值 | Biped 惰性求值 | `completeRedraw()` 后二次读 |
| Biped 骨取 `.center` 不是 pivot | Biped 骨的特性 | 用 `.transform.pos`（它没有 `.pos`） |
| 三角函数结果不对 | MAXScript 的 `sin/cos/acos` 是角度制 | 按度用 |
| 按名字比对出现假差异 | 同名对象 | 用引用快照 |
| 复制完结构后骨大面积偏位 | 缺"静止偏移对齐" | 步骤 7 |
| 手/前臂蒙皮扭转 | twist 骨只跟 BIPDRV、不跟环 | 按源结构复制 twist（位置→臂中点环、旋转→Euler+LookAt→腕环） |
| 动控制器时 Biped 不动 | 源设计如此（实测 0.000） | 不是缺陷；要反驱须另加约束层，且需单独验收 |
| 写链关节 `.rotation`/`move` 后段长变了 | IK 会重解并回写 | 只写冻结槽 |
| 末端已复位但其他关节没回去 | 单点读数不足 | 强制求值后比较全部受影响节点 |

## 14. API 速查

| 用途 | 写法 | 备注 |
|---|---|---|
| 读链段基值 | `(getSubAnim <Point>.pos.controller 1).controller.value` | `[2]` 是偏移/动态伸缩 |
| 改链段长 | 见步骤 6 | 先测长度轴 |
| 复制控制器树 | `dst.rotation.controller = copy src.rotation.controller` | 含槽位、约束、目标、权重、`pickUpNode` |
| 重指约束 | `c.appendTarget <node> <w>` + `c.deleteTarget <倒序>` | 本版本无 `SetNode` |
| `LookAt` 上方向 | `c.pickUpNode` | 必须指目标自己的骨 |
| 样条参数 | `Path_Constraint.percent` | 0–100 |
| 列表控制器 | `c.numSubs`；`getSubAnim c j` → `.controller` | 不要用 `c[j]` |
| Biped 设/读变换 | `biped.setTransform <骨> #pos\|#rotation\|#scale <值> false` | `#rotation` 为绝对世界朝向 |
| 正向依赖 | `refs.dependsOn <节点>`（递归，先 `isValidNode` 再读 `.name`） | 报告命中路径与节点 |
| 层操作 | `LayerManager.getLayerFromName`、`.addNode`、`.isHidden` | `setCurrent()` 不存在 |
| 强制求值 | `completeRedraw()` | 写后读值前 |
