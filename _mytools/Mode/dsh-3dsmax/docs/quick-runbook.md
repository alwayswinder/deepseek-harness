# Seven → Stan 操作清单（路线 1）

本文规定执行顺序与验收门槛。源 A = 原始 Seven（只读取证、不覆盖文件），目标 B = 原始 Stan（施工）；流程验证不得读取已经完成的 `.max` 副本作为结构或数值参考。算法见 [Biped 重建指南](biped-rebuild-guide.md)与[控制器迁移指南](controller-migration-guide.md)。每阶段另存里程碑，`Hold/Fetch` 会连合并一起回退。

文中数量适用于 Seven → Stan；换角色必须重新盘点。案例结果见[流程验证报告](../work/ProcessValidation_20261019/report.md)，不能把单次实测值当成固定参数。

## 0. 开工准备

| 项 | 做法与判据 |
|---|---|
| 两窗口 | 按文件路径确认原始 Seven 与 Stan；记录实例标识，避免写错窗口 |
| 目标干净 | 建 Biped 前：55 Dummy + 网格、无 Biped/IK；55 骨位置/旋转为自由 `Position_XYZ` / `Euler_XYZ` |
| 蒙皮名单 | 逐网格读取 Skin 名单并取并集；Stan 为 54，Root 不蒙皮，不能要求每个网格都含 55 骨 |
| 静止真值 | 保存 55 骨名字与世界变换到外部文件 `work/gRest_<角色>.txt`，并另存 preBiped 快照；会话全局变量不能代替落盘数据 |
| 显示态 | 见 [README 窗口与显示态](README.zh.md#窗口与显示态每轮开工前先切好)，放通控制器层的父层 |

建成 Biped 后 Nub 也属于 Dummy，必须按开工保存的骨名表识别 55 骨。

## 1. 建 Biped

按重建指南 §2 步骤 2–3，先查找图层、缺失时创建，再逐骨 `addNode`。`createNew` 的三个参数不决定最终结构，结构属性要逐项赋值并读回。

门槛：`bip001*` 71；spine 3 / neck 1 / leg 3 / fingers 5×3 / toes 1×1 / forearmTwist 2；在 Figure Mode 内装载本轮从源导出的 figure，抽查同名骨 `#scale` 与源一致。

## 2. 拟合

按重建指南 §2 步骤 4，在 Figure Mode 内以落盘静止真值拟合：整体定位、骨盆不动点修正，再做长度 → 朝向 → 位置迭代。不能用已被控制器拉偏的 UE 骨当前值作为目标。

每次写入或缩放后 `completeRedraw()`；判定前退出 Figure Mode，强制求值并在同一次调用内连续读两次。锁骨用几何方向交叉验证，不以其完整世界旋转替代可实现的两个自由度。

门槛：位置 ≤0.05、朝向 ≤0.1°、四条肢长与目标静止骨长一致。

## 3. 建测量驱动层

按重建指南 §2 步骤 5 建 `BIPDRV_*` ×55。普通驱动点不挂 Biped 父子，用位置/方向约束跟随；`BIPDRV_Root` 先摆静止，再以 `relative=true` 跟随 `bip001`，UE Root 独立约束到它。两根 twist 测量点挂在普通前臂驱动点下。

门槛：普通对应骨的驱动误差 ≤0.05 / ≤0.1°，姿态变化后不增长；Root 按保留的静止偏移验收；建立时 55 UE 骨位移为 0（容差 ≤1e-3）。

## 4. 合并并隔离名字

按控制器指南 §2 步骤 1–2：目标临时前缀必须覆盖 55 骨与 71 Biped；合并后先给源同名节点加 `SV_`，再还原目标名。

门槛：`bip001*`=71、`SV_bip001*`=71、`SV_*`=126、`TGT_*`=0、无重名。本案例合并后 1003 对象。

## 5. 复制控制器并完成引用重指

**本步必须在链几何拟合之前。** 按控制器指南 §2 步骤 5、6，复制 54 骨的位置和旋转两棵树（含两根 twist）；Root 保留独立驱动约束。52 根普通对应骨是常规位置/朝向验收集。

重指约束目标、`LookAt.pickUpNode`、ExposeTm 节点及控制根 `BIPRoot → Root`，核对 wire/script 绑定。twist 保留源的臂中点环位置约束和 `Euler + LookAt → 腕环`，不能换成裸 `Orientation → BIPDRV`。

从所有保留节点用 **`refs.dependsOn` 正向检查**，先 `isValidNode` 再读 `.name`；范围含 UE 骨、驱动点、目标 Biped、环、IK 与辅助/Expose 节点。再检查各控制器显式字段与绑定。`refs.dependents <保留节点>` 中出现源骨，表示源骨依赖该节点，不能据此断言保留节点引用源骨。

门槛：约束与绑定不再指向源骨架；不得只凭一次浅层扫描宣称所有引用已清净。

## 6. 先摆全部环，再拟合链静止几何

按控制器指南 §2 步骤 3，以落盘静止/BIPDRV 坐标摆环，然后解链。起环与腕/踝末端环先落到目标对应位置；膝/肘环保留源的近链关节语义，不能靠吸附到骨来掩盖链平面误差。

链有效局部向量为 `p1+p2`。静止拟合只写第一槽，扣除第二槽当前值；中点用父局部不动点迭代，末端只校准段长，位置交给求解器。不要对链关节 `move` 或写 `.rotation`。

门槛：起/末端误差 <2e-3、中关节误差 <0.02、两段长度与 BIPDRV 静止骨长一致。**第二槽伸缩输出不是常量**，必须按控制器指南步骤 6 验证弯曲和越界行为。

## 7. 静止偏移对齐与收尾

按控制器指南 §2 步骤 5.5 迭代手柄偏移。此时跳过起环 `Circle009/011/015/018`、末端环 `Circle010/012/016/019`、Path 点 `Point001/002`；**膝/肘环 `Circle013/014/017/020` 可参与对齐**，脚掌环不因属于肢体而自动跳过。共享手指环振荡时采用逐步验证，只接受改善结果的移动。

对齐后以 BIPDRV 静止骨长再次归一化链段，最后扫描脊柱 `percent`。扫描值按当前场景实测，不能硬填案例的 49.97/99.9968。扫描分批调用，避免 MCP 超时。

门槛：52 普通对应骨位置 ≤0.1、朝向 ≤1°。

## 8. 弯姿势、极向点与直接复位

按控制器指南 §2 步骤 4、7，双脚分别 +25Z、双手分别 +25Z、根 +10Z。在弯姿势校准极向点平面，同时复查静止；不能为了弯姿势牺牲静止门槛。

每次试动前保存所有受影响节点的世界变换；试动后直接复位，`completeRedraw()` 后比较全体受影响 Biped、驱动点与 UE 骨，不能只看被移动的末端或一条 API 读数。

门槛：姿势位置 ≤0.1、朝向 ≤1°，误差不随姿势增长；直接复位位置残差 ≤1e-4。失败应记录并重载里程碑隔离下一组；**重载恢复不算直接复位通过**。

## 9. 行为与越界验收

- 双腕、双踝、双肩环分别 +5：对应 UE 骨同向移动 5，Biped 不动（源设计），随后校验复位。
- Biped 根 +10：pelvis、head、双手、双脚均同向移动 10，随后校验复位。
- 四肢分别将末端环拉至两段总长 +20，与原始源 rig 同测：记录两段增量、链末端到环的误差及复位。表达式文本正确或段长正确都不能单独证明末端行为一致。

## 10. 显示与保存重开

按重建指南步骤 6、控制器指南步骤 8 设置显示，`boxMode` 对齐源（本案例 56/71）。保存前记录按名字索引的节点位置/旋转，另存后重开，重新解析所有节点与控制器，再逐节点比较同一批变换。

门槛：保存重开数值一致，并仍满足静止门槛。仅“重开后仍低于 0.1 / 1°”不能替代保存前后的一致性检查。源遗留层先隐藏，删除需另行确认保留节点的引用与行为。

历史轮次的 1.013° 朝向、0.127 位置，以及 0.516 / 2.793° 弯姿势残差均超门槛，不能列为已接受结果。历史证据见 [WFTest](../work/WFTest_guide-findings.md) 与 [WFTest2](../work/WFTest2_delivery-report.md)。大衣翻面仍需单独检查蒙皮与穿模，不能仅凭部分骨骼读数断定原因。

恢复时重载本轮里程碑，丢弃缓存的节点/控制器包装器，按名字重取；MAXScript 原生访问异常的原因尚未确认。全局变量不承担持久化。标识符不区分大小写；MCP 输出需拼成字符串返回，不能依赖 `print`。Figure Mode 跨调用持续，必须显式设置与恢复。

里程碑顺序：preBiped → biped → fitted → driver → merged → ctrl_copied → chains → aligned → acceptance_base → validated_base → final。文件名不代表验收通过；每阶段以检查结果为准。
