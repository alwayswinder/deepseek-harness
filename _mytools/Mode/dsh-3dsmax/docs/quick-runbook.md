# 角色适配操作清单（Biped 重建 + 控制器迁移）

本文给出**可执行的阶段顺序、通过门槛与失败处理**。算法推导在 [Biped 重建指南](biped-rebuild-guide.md)（阶段 0–3）与[控制器迁移指南](controller-migration-guide.md)（阶段 4–10）；每轮要测量的参数与记录模板在[新角色适配记录](character-adaptation-guide.md)。

本文不绑定任何固定角色：阶段里的数量、位移与节点名都从**本轮清单**推导，样例值只写在"本轮样例"列，不能直接填入新角色。

已有合格骨架、需要新建自动蒙皮时，先按 [Geodesic Voxel 蒙皮指南](skinning-geodesic-voxel/README.zh.md)完成初始权重、动作检查与保存重开验证，再进入 Biped 与控制器阶段。

## 0. 通用参数（开工时从清单算出，写进适配记录）

| 符号 | 含义 | 来源 | Seven 兼容样例 |
|---|---|---|---|
| `N_body` | 身体骨数 | body profile 的节点表 | 55 |
| `N_map` | 与 Biped 1:1 对应的普通骨 | profile 的映射表，扣除 root/twist 等特例 | 52 |
| `N_copy` | 复制控制器树的骨 | `N_body − 1`（root 例外） | 54 |
| `N_biped` | Biped 对象数 | 由结构参数算出（见重建指南步骤 2） | 71 |
| `N_collision` | 合并前要临时改名的节点 | `N_body + N_biped` | 126 |
| `N_total` | 合并后目标对象数 | 目标原对象 + 源对象 | 1003 |

**试动量按几何比例取**，写进适配记录后才执行；禁止沿用其他角色的绝对值：

| 测试 | 取法 | Seven 兼容样例 |
|---|---|---|
| 肢体弯姿势 | 肢体两段总长的 30% | 80.7 → 25 |
| 越界伸展 | 两段总长的 25% | 80.7 → 20 |
| 根平移 | 骨盆高度的 10% | 90.8 → 10 |
| 根转向 | 固定 15° | 15° |
| 环位移 | 5（cm 级场景）或总长的 6% | 5 |

## 1. 阶段总表

| 阶段 | 产物 | 一句话门槛 |
|---|---|---|
| 0 准备 | preBiped 快照、落盘静止表、适配记录 | 输入逐名核对通过，静止表行数 = `N_body` |
| 1 Biped | `biped` 里程碑 | 结构逐项一致，对象数 = `N_biped` |
| 2 拟合 | `fitted` 里程碑 | 位置 ≤0.05、朝向 ≤0.1°、各段骨长与目标一致 |
| 3 驱动层 | `driver` 里程碑 | 普通驱动点 ≤0.05/≤0.1°，`N_body` 根骨位移 ≤1e-3 |
| 4 合并 | `merged` 里程碑 | 临时前缀残留 0、无重名、两侧 Biped 各 `N_biped` |
| 5 复制+重指 | 同文件内的可测状态 | 无任何节点还引用源骨架 |
| 6 链静止几何 | `chains` 里程碑 | 起/末端 <2e-3、中关节 <0.02、段长与目标一致 |
| 7 偏移与极向点 | `aligned` 里程碑 | `N_map` 骨 ≤0.1/≤1°；极向点静止与弯曲都记录 |
| 8 姿势与复位 | 测量记录 | 姿势 ≤0.1/≤1°（并与源同姿势对照）；复位按节点类别判 |
| 9 行为与越界 | 测量记录 | 环 1:1、根平移/转向、越界末端跟环，均与源同测 |
| 10 显示与保存 | `final` 里程碑 | `boxMode` 按源清单；重开后同名节点与保存前一致 |

每阶段**另存新文件**后再做下一步；`Hold/Fetch` 会连合并一起回退，只能作补充，不能替代里程碑。

## 2. 阶段 0：开工准备

| 项 | 做法 | 门槛 |
|---|---|---|
| 两窗口 | 用完整文件路径 + Max PID 确认源 A 与目标 B；把两者写进适配记录 | 两个实例身份可复核 |
| 目标干净 | 目标场景只应有 `N_body` 根自由控制器骨 + 网格，无旧 Biped/IK/约束 | 逐名核对骨名与父子表；控制器类为自由位置/欧拉 |
| Skin 名单 | 逐网格读 Skin 骨名并取并集，与绑定设计核对 | 并集元素都属于 profile；无 Skin 记为"不适用" |
| 静止真值 | 把 `N_body` 根骨的名字、父级、世界矩阵写到外部文件 `D:\AI\work\<角色>_<日期>/gRest_<角色>.txt` | 文件存在，行数 = `N_body`；会话全局只作缓存 |
| 快照 | 另存 `<角色>_preBiped_<日期>.max` | 文件可重开 |
| 适配记录 | 按模板填完 §1–§4（含试动量） | 未填完不进入阶段 1 |

## 3. 阶段 1：建 Biped

1. 先把源 rig 的结构参数（spine/neck/leg/fingers/fingerLinks/toes/toeLinks/各类 twist）**逐项读出并记录**；创建参数本身不决定结构。
2. 图层先查后建；`biped.createNew` 之后在 Figure Mode 内逐项赋值结构，再改名、逐骨 `layer.addNode` 移层。
3. 按结构参数算出期望对象数并与实际比较：

```
N_biped = 2(root + Footsteps) + (spineLinks + 1) + 3(Neck/Head/HeadNub)
        + sides × (8 + fingers×fingerLinks + fingers + toeLinks + forearmTwistLinks)
```

**门槛**：结构读回与源一致；对象数 = 公式值（样例 71 = 58 骨 + 13 nub）。**失败**：数量不符先查结构属性是否真的写入（`getProperty` 读回），不要靠再加一次 `createNew` 掩盖。

## 4. 阶段 2：拟合

在 Figure Mode 内，以**落盘静止表**为目标（禁止读已被约束拉偏的当前值）：

1. 装入本轮从源导出的 figure（源窗口 `saveFigFile` → 目标 `loadFigFile`，两处都必须在 Figure Mode 内），逐骨比 `#scale` 并记录最大差。
2. **先测髋宽轴**：比较落盘双髋间距与 Biped 间距，确认骨盆哪个局部轴沿髋宽，单独缩放该轴，再重定位骨盆中心。
3. 整体定位：根 `#pos` 放到双髋中点、`#rotation` 取目标骨盆朝向，再用 2–3 轮把骨盆位置残差压到 0。
4. 三轮迭代：① 局部 X 定长（`coordsys local (scale 骨 [ratio,1,1])`）② 逐骨 `biped.setTransform <骨> #rotation <目标世界朝向> false`（绝对写入，一次即可）③ 可设位置的骨写 `#pos`。
5. 判定前退出 Figure Mode，`completeRedraw()`，**同一次调用内连读两次**确认稳定；再用"骨指向夹角"做几何交叉验证。

**门槛**：位置 ≤0.05、朝向 ≤0.1°、各段骨长与静止表一致（样例 0.00042 / 0.0152°）。
**失败**：出现"越调越乱"或长度停在其他角色的值 → 检查是否读到了被约束拉偏的骨，回到 preBiped 快照重来。

## 5. 阶段 3：测量驱动层

给 `N_body` 根骨各建一个 `BIPDRV_<骨名>`：放在原始静止、隐藏、**用位置+方向约束跟随对应 Biped 骨**（不挂父子；Biped 骨带非均匀缩放，挂父子会漂移）。

| 例外 | 做法 |
|---|---|
| 导出根（如 `Root`） | 驱动点先摆静止，再以 `relative=true` 跟随 Biped 根；导出根本身再由位置+方向约束跟随该驱动点 |
| twist 骨（如 `lowerarm_twist_01_l/r`） | 驱动点挂到对应前臂驱动点下；twist 骨自身的驱动结构按源 rig 原样复制 |

**门槛**：普通驱动点相对 Biped 骨 ≤0.05 / ≤0.1°；建完驱动层后 `N_body` 根骨相对静止位移 = 0（≤1e-3）；动一次 Biped 骨后误差不增长。

## 6. 阶段 4：合并与名字隔离

1. 先列碰撞清单（至少 = `N_body` 身体骨 + `N_biped` Biped 骨 + 目标已有的同名辅助点），外部保存名字与原名。
2. 目标侧加 `TGT_` → 合并源文件（`duplicate_action="rename"`）→ 给合并来的碰撞节点加 `SV_` → 还原目标名。
3. 核对：两侧 Biped 各 `N_biped`；临时前缀残留 0；源与目标唯一可解析；重名清单只允许来自源文件本身。

**失败**：出现意外自动改名或缺节点 → 丢弃合并结果，重载合并前里程碑，先修清单。

## 7. 阶段 5：复制双树 + 引用重指（必须在解链之前）

1. 对 `N_copy` 根骨（除 root）复制**位置树与旋转树**：`dst.pos.controller = copy src.pos.controller`、旋转同理。
2. 重指源骨架引用：约束目标、`LookAt.pickUpNode`、`ExposeTm` 的暴露/参考节点、控制层根节点。
   - `SetNode` 在 Max 2026 的 `Orientation/LookAt_Constraint` 上不存在：用 `appendTarget(新目标, 权重)` + `deleteTarget(旧索引)`，并利用"appendTarget 捕获当前变换"保持节点不跳。
   - `ExposeTm` 先判定它是**静态助手**还是跟随暴露节点，再决定只改字段还是改位置。
3. 从全部保留节点做**正向依赖检查**（`refs.dependsOn`，递归），并核对 wire/表达式绑定。

**门槛**：保留节点到源骨架（`SV_*`）的引用为 0；复制后骨的大面积偏移是被允许的中间态，交给阶段 7。

## 8. 阶段 6：先摆环，再拟合静止链

1. **摆全部环**：起环与腕/踝环以对应 `BIPDRV` 点落位；落位通过移动环的**普通父辅助点**完成，环到父级的局部关系保持源样（直接 `move` 环会破坏该关系）。
2. **测段长轴**：读每段的 `p1`、`p2` 与有效向量 `p1 + p2`，确认长度分量所在的分量、求解器类型；不假设 +X 或 p2.y。
3. **写静止段长**：只写冻结槽 `p1 = [L,0,0] − p2`（仅当有效向量沿该局部轴时）；否则按实测方向构造。
4. 末端位置交给求解器；**不要**写链关节的 `.rotation` 或 `move`。

**门槛**：起/末端相对 `BIPDRV` <2e-3、中关节 <0.02、两段实测长度与静止表一致。
**失败**：收紧阈值/加迭代都不改善的末端偏差，按"求解器残差"逐链记录，不要用环偏移吸收。

## 9. 阶段 7：静止偏移对齐 + 极向点 + 脊柱参数

1. **手柄迭代**：对"普通父辅助点下的环"，按关联骨的平均误差回写（阻尼 0.6），逐轮复测；跳过起环、末端环、脊柱 Path 点，以及挂在链中关节下的膝/肘环。
2. **极向点**（详见迁移指南步骤 8）：先在**静止**平面校准（校准前先量中关节离轴半径 `h`，判断是否真的退化），再按弯姿势核对平面夹角。
3. **脊柱 Path `percent` 最后扫描**：按当前场景实测最优点，分批采样。

**门槛**：`N_map` 根骨相对驱动点 ≤0.1 / ≤1°；极向点静止与弯姿势的中关节误差都要记录，任一超门槛即失败，不能当取舍。

## 10. 阶段 8：姿势与直接复位

**驱动源必须分清楚**：差分验收的姿势由 **Biped 骨**驱动；"动环"是独立的行为测试（阶段 9），不能用来判差分。

| 子项 | 做法 | 门槛 |
|---|---|---|
| 8A 弯姿势差分 | 按记录位移分别移动双脚、双手对应的 Biped 末端骨 | `N_map` 骨 ≤0.1 / ≤1°，误差不随姿势增长；与源同姿势对照 |
| 8B 复位 | 每组试动前快照全部受影响节点，试动后直接移回并逐节点比较 | 非求解器节点 ≤1e-4；求解器关节单独列出并与源基线对照 |
| 8C 姿势隔离 | 一组失败后重载里程碑再测下一组 | 重载恢复**不算**直接复位通过 |

## 11. 阶段 9：行为与越界

| 子项 | 做法 | 判据 |
|---|---|---|
| 环 1:1 | 分别移动腕/踝/肩环记录位移 | 对应 UE 骨等量同向；Biped 是否跟随按**源实测**判定（Seven 源为 0） |
| 根平移/转向 | 按记录量平移与转动 Biped 根 | pelvis/head/双手/双脚保持预期跟随；与源同测 |
| 越界 | 把末端环拉到两段总长 + 记录超出量 | 记录两段增量、末端到环的距离，与源在可比伸展度下同测 |
| 引用复查 | 阶段 5 的正向依赖检查再跑一次 | 仍为 0 |

## 12. 阶段 10：显示与保存重开

1. `boxMode` 按源 rig 同职责节点清单对齐（数量从清单算，不固定）。
2. 两个窗口视口统一（Front / Standard / Edged Faces）；源遗留层隐藏，删除需另行确认引用与行为。
3. 保存前按**节点引用**记录位置与旋转（同名节点不能按名字比对），另存后重开，按名字重新解析后逐节点比较。

**门槛**：非求解器节点保存前后一致；求解器驱动节点（IK 链关节等）单独报告残差并与源基线对照；重开后仍满足阶段 7 的静止门槛。

## 13. 恢复与记录纪律

- 每阶段先另存再继续；失败重载本轮里程碑隔离，不靠反复"修正"。
- 写入后 `completeRedraw()`；结论在同一次调用内读两次确认。
- 会话全局不承担持久化：骨名表、静止表、映射表、语义表全部落盘。
- 标识符不区分大小写；日志与结论用字符串拼接返回，不依赖 `print`。
- 每阶段的失败节点、残差、与源对照值都要写进适配记录，文件名不构成验收。
