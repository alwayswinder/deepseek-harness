# @local/dsh-appearance-plus

[English](README.md) | 中文

## Summary

该配置层在插件页增加五套颜色主题、背景图片编辑器和空闲锁屏。偏好保存在当前 DSH 设置文档中；选取的本地图片只保留在对应浏览器或 Desktop 配置中。组合包只改变显示效果，不改动对话或模型请求。

<a id="use-this-package"></a>
## 使用本包

组合包启用后，打开**插件 → 外观增强**。可选择默认、护眼绿、暖纸、海蓝、柔紫或深夜。每项选择都会立即应用并自动保存。

**背景图片。** 可以粘贴 HTTP(S) 图片地址，也可以选择本地图片。页面会立即预览文件，把它转换为容量受限的 WebP 图片，并拒绝超过 20 MB 的本地输入。图片亮度、界面遮罩、模糊和铺放方式也会自动保存；滑块和图片地址使用短暂延迟，把连续修改合并后写入。图片到达屏幕的强度是「图片亮度 ×（1 − 界面遮罩）」，界面遮罩决定最终还能看到多少。默认 0.62 让壁纸清晰可见而界面依然易读；滑块下限 0.15 让侧栏、消息区、输入框、设置行和代码块一起变透，嵌套表面叠加后壁纸仍能透出大半。下拉菜单和提示浮在图片之上，另按不低于 0.82 的底色绘制，保证文字可读。

**锁屏壁纸。** 第二张独立图片，自己一套铺放方式。勾选**空闲时启用**后，只要没有任务在运行、并且一段时间内没有点击、滚动、按键或鼠标移动（默认 20 秒），客户端就进入锁屏：这张图片在 2.4 秒内盖住整个页面，对话和侧栏一并遮住。之后任何一次点击、滚动、按键或鼠标移动都会在 0.22 秒内交还界面；锁屏不透明时，用于解除的那一次点击会被它吃掉，不会落到它遮住的控件上。任务运行期间不进入锁屏，设置页也始终不解锁屏，保证控件随时可点。锁屏只占用页面像素：窗口不会被缩放或切到全屏，所以操作系统自带的最小化/最大化/关闭按钮依然显示在它之上。

Web 端在终端安装：

```text
dsh plugin --profile web add file:<repo>/_mytools/Plugins/appearance-plus
```

Desktop 拥有自己的配置（`$DSH_HOME/profiles/desktop`），并拒绝 `dsh plugin --profile desktop`；因此要在应用的**插件 → 添加插件**对话框中填入本目录的绝对路径，每台机器安装一次。裸绝对路径和 `file:` 形式都可以：插件必须能从自身目录解析 `@deepseek-ai/schemastery`，而 `build.bat`、`build-desktop.bat`、`start-dsh.bat` 和 `start-desktop.bat` 都会在运行前把 `_mytools/Plugins/node_modules/@deepseek-ai/schemastery` 链接到 vendor 中的副本。缺少该链接时 Host 无法导入插件，会把组合包报告为启用失败。

首次安装后重启 Desktop 或重新加载 Web 应用，使浏览器包进入客户端图。

<a id="understand-the-implementation"></a>
## 了解实现

<details>
<summary>实现细节——点击展开</summary>

[`index.js`](index.js) 注册 `appearance-plus` 设置命名空间。[`client.js`](client.js) 通过具名的 `ctx.theme` token 覆盖层应用配色，把两张已保存的图片投影到自有样式表，并通过 `plugins.item` 提供配置页。覆盖层以可持久保存的内置浅色或深色偏好为基础，因此设置同步不会替换已选配色。[`cordis.patch.yml`](cordis.patch.yml) 挂载 Host 行。

两张图片由两份自有样式表承担。一份声明 `#root` 之后的背景层，以及压在所有东西之上的锁屏层（高于每一个 portal 出来的菜单、弹窗和提示），锁屏过渡只依赖其中唯一一个用 `@property` 注册的淡化系数；另一份把每个表面 token 从当前主题重新推导成基于已保存遮罩 alpha 的 `color-mix(...)`——因此所选配色不会被一张写死的颜色表替换，而是穿过背景图片保留下来。空闲计时器是一个本地 500 毫秒轮询加上 pointer、wheel、key 三类监听器；「有任务在运行」读的是 `ctx.sessions.list` 中任意一行的 `running` 标记，走可选注入，因此没有会话服务的 profile 只是永远不会进入锁屏。鼠标移动只有在指针真的移动过时才算操作，因为缩放或移动窗口会让引擎在原位置补发一次移动事件。

两个图片槽各自持有自己的本地存储键与持久标记：选择的本地图片以压缩 Data URL 形式存储在当前浏览器配置中，设置文档只携带标记，`settings.yaml` 不包含图片字节。只有存放过该图片、之后又丢失的来源才会清除这个标记；其他来源只会提示本设备没有这张图，并保持共享设置不变，因为设置文档是共享的，而本地存储按来源隔离。

</details>

<a id="model-experience"></a>
## 模型体验

无。组合包只改变浏览器显示，不增加模型可见输入、提示词内容、工具或会话事件。

## 已知限制与延后工作

本地图片不会在 Desktop、Web 或其他浏览器配置之间同步；每张图都需要在每个界面分别选择，没有副本的界面会在页面上说明。锁屏过渡依赖 `@property`，表面透明依赖 `color-mix`；不支持它们的引擎会直接切换状态而没有过渡。操作系统自带的最小化/最大化/关闭按钮画在页面之上，属于窗口边框，锁屏盖不住它们，本组合包也不会为了盖住它们而改变窗口状态。背景透明度作用于使用主题 token 的界面，而嵌入式终端、文档预览和远程网页可以保留自己的不透明背景——锁屏画在界面之上，因此这些内容同样会被遮住。
