1. 项目概述
产品名称：DSH 养鱼游戏插件 (DSH Aquarium)

产品定位：一款运行在DSH桌面端右侧边栏的休闲解压小游戏。用户在工作/娱乐间隙，可以进入沉浸式的像素海底世界，通过投喂和吹泡泡与鱼儿互动。

目标用户：DSH用户，需要短暂放松、喜欢像素风或桌面宠物的人群。

2. 用户故事
作为一名用户，我希望在DSH右侧边栏看到一个悬浮的小鱼图标，点击后能全屏进入海底世界，让我在工作间隙得到放松。

作为一名用户，我希望能在全屏模式下看到鱼儿自由游动、水草摇摆、气泡上升的动态画面，而不是一张死板的图片。

作为一名用户，我希望点击“投喂”按钮后，能撒下鱼食，并看到鱼儿游过来抢食。

作为一名用户，我希望点击“吹泡泡”按钮后，画面能出现大量上升的气泡，增加互动趣味性。

作为一名用户，我需要一个直观的退出方式（如ESC键或返回按钮），以便随时回到DSH主界面。

3. 功能需求
3.1 入口与退出

悬浮按钮：在DSH右侧边栏提供一个常驻的悬浮按钮（建议图标：像素小丑鱼或鱼缸）。

进入游戏：点击悬浮按钮，全屏覆盖DSH界面，进入养鱼模式。

退出游戏：

按键盘 ESC 键。

点击画面右上角的“退出”按钮。

再次点击右侧边栏的悬浮按钮。

3.2 核心画面（动态渲染）

背景层：深海渐变蓝色背景，顶部有动态的丁达尔光线（光柱）投射。

环境层：

水草：两侧和底部的水草持续进行正弦波摆动。

珊瑚：静态或带有轻微呼吸/发光动效。

气泡：背景中随机生成缓慢上升的气泡，到达顶部后破裂。

生物层：

初始包含 3-5 条不同种类的像素鱼（如小丑鱼、蓝吊）。

游动AI：鱼群在画面内随机游走，碰到边缘自动平滑转向，尾巴持续摆动。

交互反馈：鼠标点击画面时，附近的鱼会受惊加速游走。

3.3 互动功能（右侧面板）

进入全屏后，右侧（或底部）显示一个半透明的功能面板，目前包含两个按钮：

投喂 (Feed)：

点击后，在当前鼠标位置或画面中心上方生成几粒鱼食（像素颗粒）。

鱼食受重力影响缓慢下落。

鱼类检测到鱼食后，切换为“追踪”状态，游向鱼食。

触碰到鱼食后，鱼食消失，鱼的“饱食度”增加（可选），并产生微小的粒子特效。

吹泡泡 (Bubbles)：

点击后，在画面底部或鼠标位置生成一连串大小不一的泡泡。

泡泡具有浮力，呈波浪形上升，碰到画面顶部破裂。

4. 非功能需求
性能：全屏运行时保持 60FPS，CPU/GPU占用率不超过 %（根据实际测试定），不影响DSH其他功能的使用。

兼容性：适配不同分辨率的显示器（包括4K和带鱼屏），画面比例自适应。

持久化：退出游戏后，再次进入时，保留上次的鱼儿数量、位置和状态（通过 localStorage 或 DSH 插件存储实现）。

5. UI/UX 设计规范
美术风格：全像素风（Pixel Art），色板参考概念图，以深蓝、青绿、亮橙、粉紫为主色调。

UI组件：

按钮：像素风格边框，悬浮时有微微放大的动效。

文字：使用像素字体（如 Zpix 或 Fusion Pixel）。

面板：半透明磨砂玻璃质感（毛玻璃效果）或像素风格面板。

鼠标指针：在游戏模式下，鼠标指针可替换为像素鱼网或十字准星。

6. 技术架构建议
渲染引擎：HTML5 Canvas + 原生 JS（或 PixiJS 提升渲染性能）。

动画循环：requestAnimationFrame 配合 deltaTime 保证不同刷新率下的速度一致。

状态管理：

Fish 类：包含坐标、速度、目标点、状态机（游荡、追食、受惊）。

Bubble 类：包含坐标、速度、大小、生命值。

Food 类：包含坐标、下落速度。

DSH集成：

使用 DSH 的 Sidebar API 注册悬浮按钮。

使用 DSH 的 Overlay/Window API 创建全屏透明窗口，注入 Canvas。

监听键盘事件（ESC）和鼠标事件进行交互。

7. 开发里程碑规划
第一阶段（基础框架）：跑通DSH侧边栏按钮 -> 唤起全屏Canvas -> 渲染静态背景图（概念图作为占位） -> ESC退出。

第二阶段（动态核心）：实现水草摇摆、气泡粒子系统、单条鱼的游动逻辑与边界反弹。

第三阶段（互动功能）：完成右侧功能面板UI，实现投喂（鱼食下落与鱼的追踪）和吹泡泡功能。

第四阶段（打磨优化）：替换精细的像素动画素材（Spritesheet），加入受击特效、声音（可选），优化性能，实现状态持久化。
