# Desktop pet

An always-on-top window of its own: it changes expression with the agent state, tucks the DSH window away or brings it back on a click, and its right-click menu opens chat, Git changes, music, and screenshots.

The settings below apply to this machine only; turning off **Enable pet** ends the pet process immediately, and turning it back on starts it again.

Every menu entry, where the music downloads to, and the rest of the document are in `README.md` in the plugin directory.
