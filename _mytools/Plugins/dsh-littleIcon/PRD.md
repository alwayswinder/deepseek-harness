一、 可行性分析
结论：完全可行，且技术方案非常成熟。

桌面悬浮窗与虚化效果：无论是 Electron、Tauri、WPF 还是 Qt，都原生支持无边框窗口（Frameless Window）和透明窗口（Transparent Window）。通过调整 CSS 的 opacity 或原生窗口的透明度参数，可以轻松实现“虚化悬浮”和“鼠标移入实化”。

点击最小化/还原与移动：可以通过绑定鼠标点击事件调用主程序（DSH）的最小化/还原 API。拖拽功能可以通过监听鼠标按下、移动和抬起事件来实现窗口位置的动态更新。

状态联动：插件与 DSH 主程序之间可以通过 IPC（进程间通信，如 Electron 的 ipcRenderer / ipcMain）或 WebSocket 建立通信，主程序将“干活中”、“睡觉中”的状态广播给插件，插件根据状态切换加载不同的 GIF 或 Sprite Sheet。

性能：像素风动图尺寸较小（如 64x64 或 128x128），对内存和 CPU 的占用极低。

注：你在需求中先提到“桌面端右侧”，后提到“虚化悬浮在左边”，PRD中我以“默认悬浮在右侧边缘（支持拖拽改变位置）”为准。

二、 产品需求文档 (PRD)
1. 产品概述
产品名称：DSH 像素鲸鱼娘桌宠插件 (DSH Whale Girl Pet)

产品目标：为 DSH 桌面端增加一个可爱、轻量、实用的悬浮挂件，通过像素动图增加软件的陪伴感，并提供快捷的窗口控制功能。

目标用户：DSH 桌面端用户。

2. 核心功能与交互逻辑
2.1 外观与基础展示

展示一个正方形区域（建议默认 128x128 像素），内容为像素风格的鲸鱼娘动图（参考原图的蓝发、女仆装、呆毛特征，但简化细节）。

默认贴在屏幕右侧边缘，始终置顶。

2.2 交互状态（鼠标行为）

闲置状态：半透明（虚化），如 opacity: 0.4，不干扰用户视线。

鼠标悬停 (Hover)：渐变为完全不透明（opacity: 1），并带有轻微放大或高亮效果。

鼠标拖拽：鼠标左键按住可拖拽该图标在屏幕任意位置移动（需限制不可完全移出屏幕外）。

2.3 点击逻辑（DSH 控制）

单击行为：

当 DSH 处于正常显示状态时，单击宠物 -> DSH 最小化到系统托盘/任务栏，宠物图标依然留在屏幕上。

当 DSH 处于最小化状态时，单击宠物 -> DSH 窗口还原并置顶。

2.4 状态联动（动图切换）

插件需监听 DSH 的工作状态，显示不同的动图：

干活中 (Working)：鲸鱼娘高速敲击键盘、冒汗或忙碌转圈。

睡觉中 (Sleeping)：鲸鱼娘闭眼，旁边有 Zzz 气泡。

打盹/空闲 (Idle)：鲸鱼娘待机呼吸、偶尔眨眨眼。

出错/警告 (Error)：鲸鱼娘呈现图片中的“难道说”惊讶表情。

3. 异常与边界情况
当 DSH 意外崩溃关闭时，插件应有自我保护机制（不随之崩溃，或提示用户）。

多显示器场景下，需要正确计算拖拽的坐标和屏幕边缘。

退出插件：在任务栏托盘提供右键菜单“退出插件”。
