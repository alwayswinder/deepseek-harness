# 断星协议：回合制节奏战斗 Demo

纯 HTML、CSS、JavaScript 实现的单场 2D 战斗原型，无构建步骤、无运行时依赖。

## 启动

推荐在本目录启动一个静态文件服务器：

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。也可以直接双击 `index.html` 运行。

## 操作

- `1` / `2` / `3`：选择玩家技能，也可点击技能卡片。
- `鼠标左键`：玩家轻击；`鼠标右键`：玩家重击。三套连招只使用轻击与重击。
- `鼠标左键`：全 PERFECT 攻击后触发追击 QTE。
- `鼠标右键`：在敌人攻击回合防御；全部 PERFECT 会使敌人巨大后退并进入易伤状态。
- 触屏设备可使用右下角虚拟按键。

## 玩法规则

- `PERFECT`、`GOOD`、`MISS` 三档判定会影响攻击伤害或防御结果。
- 战场中央的圆环会在每个节拍重新旋转一圈；圆环蓄满并整体高亮时是 `PERFECT` 输入窗口。
- 三套招式使用按动作设计的非等距节奏；角色会在判定点前抬刀或蓄力，并在圆环满圈时接触目标。完全不输入仍造成基础伤害，GOOD 与 PERFECT 提升命中效果和最终伤害。
- 月蚀连斩和贯星重刃各获得 1 格脉冲能量；苍穹处决消耗 2 格。
- 完美弹反会削减敌人架势；连续全部完美可立刻破势。
- 破势后的下一次攻击获得 35% 伤害加成。
- 战斗失败或胜利后都可以立即重新挑战。

所有视觉内容均由 Canvas/CSS 原生绘制，音效由 Web Audio API 实时合成。
