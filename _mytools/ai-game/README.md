# 断星协议：ATB 即时回合制节奏战斗 Demo

纯 HTML、CSS、JavaScript 实现的单场 2D 战斗原型，无构建步骤、无运行时依赖。

## 启动

推荐在本目录启动一个静态文件服务器：

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。也可以直接双击 `index.html` 运行。

## 操作

- `1` / `2` / `3`：选择蓄力、变身或攻击，也可点击技能卡片。
- `蓄力`：消耗 1 AP，使下一次攻击的基础伤害变为 2 倍，PERFECT 伤害变为 3 倍。
- `变身`：消耗 1 AP，当前及下一次玩家控制窗口内，攻击判定从 4 次减少为 2 次，总伤害保持不变。
- `攻击`：消耗 1 AP，生成固定 4 次、左右键随机的判定；变身期间改为 2 次。
- `防御架势`：消耗 1 AP；如果 Boss 在玩家下一次获得控制权前攻击，则进入右键弹反序列。
- `跳过行动`：不消耗 AP，保留当前行动力并重新进入双方 ATB 竞速；下一条 ATB 率先充满的一方获得行动权。
- `鼠标左键`：玩家轻击；`鼠标右键`：玩家重击。每次攻击都会重新随机轻重组合。
- `鼠标左键`：全 PERFECT 攻击后触发追击 QTE。
- `鼠标右键`：仅在提前选择防御后，于 Boss 攻击中弹反；全部 PERFECT 会使敌人巨大后退并进入易伤状态。
- 触屏设备可使用右下角虚拟按键。

## 玩法规则

- `PERFECT`、`GOOD`、`MISS` 三档判定会影响攻击伤害或防御结果。
- 玩家与 Boss 按各自速度积累 ATB；ATB 满后获得行动力。
- 玩家速度为 72，Boss 速度为 36，恰好是玩家的一半；全局 ATB 填充倍率提高后，玩家从空条到满条约需 2.5 秒。
- 玩家最大生命为 60，最多储存 3 AP；Boss 最大生命为 320，最多储存 2 AP，攻击伤害更高。
- 玩家拥有 AP、选择指令、执行攻击连段或处理追击时，双方 ATB 都会暂停，玩家可以不限时思考并连续行动。
- Boss 的攻击预警、弹反/命中和动作收尾期间，双方 ATB 同样暂停；Boss 完成整套动作后才恢复竞速。
- 玩家每次获得控制权只计算一次行动；在同一控制窗口内连续消耗多个 AP，不会额外消耗变身的持续次数。
- Boss 获得第 1 AP 时有 20% 概率跳过并继续积攒；达到 2 AP 后发动蓄力连招，伤害翻倍且节奏加快 1.2 倍。
- 蓄力会让玩家周围出现旋转光弧和金色能量粒子；变身会产生紫色光环、轨道和残影粒子；防御姿势会在玩家身前展开琥珀色护盾。
- 防御只持续到下一次玩家控制权到来；期间 Boss 若先攻击便可弹反，否则防御失效。未准备防御时，Boss 会直接造成伤害且不会出现弹反提示。
- 战场中央的圆环会在每个节拍重新旋转一圈；圆环蓄满并整体高亮时是 `PERFECT` 输入窗口。
- 角色会在判定点前抬刀或蓄力，并在圆环满圈时接触目标。完全不输入仍造成基础伤害，GOOD 与 PERFECT 提升命中效果和最终伤害。
- 完美弹反会削减敌人架势；连续全部完美可立刻破势。
- 破势后的下一次攻击获得 35% 伤害加成。
- 战斗失败或胜利后都可以立即重新挑战。

所有视觉内容均由 Canvas/CSS 原生绘制，音效由 Web Audio API 实时合成。
