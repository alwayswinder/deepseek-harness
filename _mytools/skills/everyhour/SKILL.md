# everyhour · 整点推送

用户说 **everyhour** 就进入推送状态：每个整点推一条，他打 0–10 分，用分数改选材。说「停」「别推了」就退出。

目标不是信息量，是**他想转发给别人的那条**。

## 每次触发做什么

1. 读 `<个人隐私库>/feed/preferences.md`（偏好与打分）
2. 读 `<个人隐私库>/feed/history.md` 的最近 100 条（去重）
3. 选一条，**只发一条**
4. 追加一行到 `history.md`
5. 不问「还要吗」，不多发，不解释流程

个人隐私库的位置：取 temp-space 插件的当前数据目录 —— 先看 `$DSH_HOME/temp-space.location.json`，没有就看所用 profile 的 `cordis.patch.yml` 里 `dsh-temp-space` 的 `dataDir`。

## 选材

- 类型池：历史、文化、科技、金融、自然科学、冷知识、当日趣闻。
- 标准：**反直觉、有具体细节（数字/时间/人名）、可验证、能一句话转述**。
- 当日新闻优先，但必须是「有意思」而不是「重要」——不复述行情、不复述政策原文。
- 避雷：鸡汤、成功学、烂大街的伪冷知识（「爱因斯坦数学不及格」「拿破仑矮」这类）。
- 每条结尾一句「为什么有意思」，不超过一行。

## 打分闭环

- 用户回复 0–10 的数字，就是对最近一条的打分。
- 记入 `preferences.md`：日期、摘要、类型、分数。
- 推送前看判断段：高分类型加权，低分类型避开。
- **连续 3 条低于 5 分 → 换赛道**：换主题池，或换叙事方式（比如从「冷知识」换成「正在发生的事」）。
- 用户明确说「不喜欢 X」时，直接写进判断段的避雷清单。

## 输出

一条消息，手机上两到四行，不用标题、不用编号列表。像跟朋友说一件事，不像简报。

## 边界

- 每小时一条，深夜时段（23:00–08:00）不推。
- 抓不到可靠来源就不发，宁可这一小时空着，也不编。
- 不推送投资建议，金融类只讲事实和机制。
